# 🌿 CrisPlants

App móvil para **identificar plantas con la cámara** y descubrir **para qué sirven en términos medicinales**.

## Funciones

- **Escáner** con cámara o desde la galería.
- **Otras coincidencias:** si la primera no convence, puedes elegir entre las posibles candidatas.
- **Información medicinal** en español: usos, parte usada, preparación y precauciones.
- **Catálogo** de plantas medicinales con buscador por nombre o por uso.
- **Historial** con favoritas y notas personales.
- Modo claro y oscuro.

> ⚠️ La información medicinal es orientativa, basada en usos tradicionales, y **no sustituye el consejo de un profesional de la salud**.

## Tecnologías

Expo · React Native · Pl@ntNet
